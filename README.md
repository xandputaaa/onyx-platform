# ONYX Command House — Clean Rebuild 001

Fresh Vite/React application built only from the approved ChatGPT Command House prototype and Smart Scheduler. The prior repository file tree was deliberately not inherited.

## Features
- Animated silver spiral with flow/surge/still modes and responsive cinematic entry
- Home command center with preview-only AI controls
- Smart Scheduler with separately editable Gym and Lunch
- Protected Work and work break; explicit edits required
- Day-off switch, conflict checks, task completion and additions
- Local browser persistence via localStorage (per device/browser; not cloud sync)
- Health meal log, calorie and protein estimates, systems overview

## Run
`npm install && npm run build && npm run start`

## Limitations
The 5:00 AM work start and 8:00 AM break are user-provided. 1:00 PM work end and other task times are examples. No microphone, AI backend, account sync, or external systems are connected. This rebuild replaces files on the main branch but historical Git commits remain accessible.
